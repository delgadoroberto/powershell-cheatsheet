# Security Policy

## Supported Versions

This repository is primarily documentation and example scripts.

Security fixes and documentation updates are applied to the latest version available on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue in one of the example scripts or documentation, please do not open a public issue.

Instead, report it privately through GitHub Security Advisories if available.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

## Scope

Examples provided in this repository are intended for educational and administrative purposes.

Always review and test commands before executing them in production environments.

Some examples may require administrative privileges or may modify system configuration.

## Disclaimer

The author is not responsible for any damage caused by incorrect use of the examples provided in this repository.

Always validate commands in a safe or test environment before using them on production systems.
