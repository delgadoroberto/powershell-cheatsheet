# Contributing

Thank you for your interest in contributing to this repository.

This project aims to provide a practical and well-organized PowerShell reference for system administrators, DevOps engineers, and cybersecurity professionals.

## Ways to Contribute

Contributions are welcome, including:

- Fixing errors or typos
- Improving documentation
- Adding practical examples
- Suggesting new PowerShell commands
- Reporting outdated information
- Improving formatting and readability

## Guidelines

Before submitting a contribution, please ensure that:

- Markdown formatting is consistent.
- Examples are tested and produce the expected results.
- Commands are compatible with the documented PowerShell version.
- Explanations are clear and concise.
- Code examples use proper PowerShell syntax highlighting.

Example:

```powershell
Get-Service | Sort-Object Status
```

## Pull Requests

Please provide a clear description of your changes.

Whenever possible, include:

- What was changed
- Why the change was made
- Screenshots (if documentation is affected)

## Issues

If you find incorrect information or want to request new content, please open an Issue before submitting major changes.

## Code Style

This repository follows these principles:

- Keep examples practical.
- Prefer built-in PowerShell cmdlets.
- Explain commands before showing examples.
- Include cybersecurity use cases whenever applicable.
- Keep documentation beginner-friendly while remaining useful for experienced users.

Thank you for helping improve this project.
